心中的VRChat

无需 Pulsoid API Token，在后台读取心率组件；点击「开始推送」不打开网页窗口。

心率设备 → 手机 Pulsoid → 心率组件网页 → 本软件 → VRChat

五步开始

1 · 手机上传手机打开 Pulsoid App，连接兼容心率设备／广播工具并开启上传，确认网页组件的心率会实时变化。
2 · 粘贴链接解压并运行 PulsoidVRC.exe。保持默认「网页读取」，粘贴你自己的 Pulsoid 心率组件直接链接。无需填写 API Token。
3 · 后台推送点击「开始推送」，后台自动识别唯一数字，不弹网页。如果提示存在多个数字，停止后单独点击「定位数字」选择一次心率，保存后设置窗口自动关闭。再开始推送即可。
4 · 打开 OSCVRChat 动作菜单打开 OSC → Enabled，并在聊天框设置中允许 OSC 消息。软件地址保持 127.0.0.1:9000。
5 · 查看消息聊天框默认每 2 秒更新一次，例如 ♥ 心率 82 BPM。可修改模板及间隔。开始前也可用「测试消息」检查聊天框通路。

需要了解的行为

网页没有传感器原始时间戳。为避免持续发送卡住的数字，连续 15 秒不变化会暂停发送，变化后恢复。真实心率恰好保持同一整数时也可能暂停。
  • 请使用不需要另行登录的个人组件直链。后台浏览器不导入你平时浏览器的登录状态。
  • 刷新会重新识别；定位失效或有多个数字时暂停发送，可停止后重新「定位数字」。更换链接不会套用旧位置。
  • 支持网页文字数字，不支持图片、Canvas 或 SVG 数字；请使用文字式心率组件。
  • 请打开组件直接网址，不要使用控制台中的 iframe 预览。
  • 日常推送没有浏览器窗口；仅手动点击「定位数字」会打开设置窗口。定位过程不发送聊天消息。停止推送会结束后台浏览器。
  • 手机与电脑都需联网；不要求同一 Wi-Fi。需安装 Edge 或 Chrome，无需安装扩展或其他运行环境。
